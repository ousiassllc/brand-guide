トースト Toast（下書き）

軽い完了・コピー・短いエラー向き。確認や破壊的操作はモーダル／インラインアラートを使う。

出し方
  • 位置：画面下中央（desktop / mobile 共通）。端から 24px
  • 出現：下から 8px＋フェードイン（--motion-fade-in）／退出：フェードアウト（--motion-fade-out）
  • 自動で消える：通常 3秒／アクション付き 5秒
  • 同時表示は原則 1つ（新しいものが出たら前を置き換え）
  • 文言は短く1行。動詞止め可「コピーしました」
中身・禁止
  • 種類：情報（既定）／成功は同じ見た目で文言だけ変える
  • アクションは1つまで（例「元に戻す」SemiBold）
  • エラーの詳細説明・フォーム検証はトーストにしない
  • プリズム色・複数ボタン・長文・リンクの羅列は禁止
  • reduced-motion 時は移動なし・フェードのみ

見本 Demos

ボタン hover（背景色のみ・180ms）

動かさない。色/背景だけ。フォーカスリングは即時。

リップル（クリック点から円・280ms）

ボタンとクローズ（アイコンボタン）に共通。小さくファンっと広がって消える。

フェードイン／アウト（in 320ms · out 240ms）
カードが静かに現れます

出現は緩やか（320ms ease-out）、退出はやや短く（240ms ease-in）。移動は 8px。

ルール Rules

Do
  • 状態の変化・出現/退出を伝えるときだけ動かす
  • opacity＋小さな移動（4–8px）を使う
  • ホバーは色/背景のみ ≤180ms、フォーカスは即時〜120ms
  • ボタン／クローズの押下は小さくリップル（円がファン）
  • フェードイン 320ms / フェードアウト 240ms。モーダル出現は slow 帯／シート：下から 280ms
  • スクラムはオーバーレイと一緒にフェード
Don’t
  • 装飾だけのループ・視差・大きな移動
  • バウンス／スプリング、scale ポップ（使うなら最大 1.02）
  • UI 上のプリズム（虹色）モーション
  • 300ms を超える UI トランジション
  • reduced-motion を無視する
prefers-reduced-motion: reduce — 装飾的な動き（移動・スライド）は無効化。必要な opacity フェードは ≤100ms またはなし。スピナーなど処理中表示は維持。

ガイドに定義のないモーションパターンも 「ガイドにないものは使わない」 の対象です。
