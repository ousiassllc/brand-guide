軽い完了・コピー・短いエラー向き。確認や破壊的操作はモーダル／インラインアラートを使う。

出し方
  • 位置：画面下中央（desktop / mobile 共通）。端から 24px
  • 出現：下から 8px＋フェードイン（--motion-fade-in）／退出：フェードアウト（--motion-fade-out）

モーション Motion

基本的に静かだけど動きがある。静か・短く・目的があるときだけ。フェードイン 320 / フェードアウト 240。派手な動き、バウンス、UI 上のプリズム（虹色）モーションは使わない。

ルール Rules

Do
  • 状態の変化・出現/退出を伝えるときだけ動かす
  • opacity＋小さな移動（4–8px）を使う
  • ホバーは色/背景のみ ≤180ms、フォーカスは即時〜120ms
  • ボタン／クローズの押下は小さくリップル（円がファン）
  • フェードイン 320ms / フェードアウト 240ms。モーダル出現は slow 帯／シート：下から 280ms
  • スクラムはオーバーレイと一緒にフェード
Don’t
  • 装飾だけのループ・視差・大きな移動
  • バウンス／スプリング、scale ポップ（使うなら最大 1.02）
  • UI 上のプリズム（虹色）モーション
  • 300ms を超える UI トランジション
  • reduced-motion を無視する
prefers-reduced-motion: reduce — 装飾的な動き（移動・スライド）は無効化。必要な opacity フェードは ≤100ms またはなし。スピナーなど処理中表示は維持（回転は止め、先端のアークと aria-busy で処理中を残す。スピナー）。

ガイドに定義のないモーションパターンも 「ガイドにないものは使わない」 の対象です。
