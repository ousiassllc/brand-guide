# Ousiass UI カラーガイド

Ousiass 全プロダクト共通の UI カラー設計ガイドラインです。**確定（2026-11-05）**。スイッチ・ラジオの状態など一部は推奨案（未確定）です。

- 公開ページ: https://ousiassllc.github.io/brand-guide/
- フォント: Sora / Noto Sans JP / JetBrains Mono (OFL, Google Fonts)
- ライト／ダーク切替の参照実装: `theme.js`（切替の動作）と `theme-control.css`（切替コントロール 3 形の見た目の差分）。`theme-control.css` は基底の `.seg`（枠・padding・選択中の塗り・フォーカスリング・svg の大きさ）に足す差分で、**基底の `.seg` は各ページ側（`index.html` と `tokens-preview.html` のインライン `<style>`）にある**ため、`theme-control.css` だけでは動かない。`index.html` と `tokens-preview.html` が head で同期読み込みする（FOUC を避けるため。相対パス）。規定は index の「ライト／ダーク切替」
- 回帰チェック（`scripts/check-*.sh` 全 8 本。どれも `scripts/check-xxx.sh [ルート]` で動き、ルート省略時はこのリポジトリ。末尾に `PASS n / FAIL m` を出し、FAIL があれば exit 1）:
  - grep・awk だけで見る（依存なし）: `check-states.sh`（Issue #10・#12・#14・#16 ほか。状態・切替・フォーカス・スピナー・z・影・テーマ切替の 3 形・設定画面のパーツ・index のジャンプ導線の並びが節の出現順と一致 #88・tokens-preview と `theme-control.css` の静的な規則 #6・#85・#87・#89・#90・#91・#93（z-index はトークンか局所の 0〜2））、`check-scrollbar.sh`（#3）、`check-typography.sh`（#2）、`check-overlay.sh`（#18 の重ね塗り）、`check-app-ui.sh`（#20 の面・文字 5 段 #96（22 / 16 / 15 / 14 / 13、ウェイトは最大 600）・余白と丸み・使い分け表 `.ut` の区切りと th #86・フィルタチップ `.fchip.on` の選択）、`check-product-names.sh`（#55 の製品の名前）。このうち `check-states.sh`・`check-scrollbar.sh`・`check-typography.sh`・`check-overlay.sh`・`check-app-ui.sh`・`check-product-names.sh` は共通ヘルパー `scripts/lib.sh` を読み込む（前提のファイルが無いときは「ERROR: <path> がありません」を 1 行出して exit 2。PASS は出さない）
  - 実行して測る（Node 22 以上と Chrome / Chromium が前提。Chrome の場所は環境変数 `CHROME`。省略時は `google-chrome` / `chromium` を探す。Node か Chrome が無いときは SKIP を表示して exit 0。npm パッケージは不要）: `check-render.sh`（Issue #54。見本の寸法・文字サイズ・コントラスト・reduced-motion・横スクロール・リンク先・id 重複を Light / Dark × 1280px / 375px で実測する。あわせて Tab 巡回のフォーカスリング・`#toast` の a11y ツリーと本文の出し入れ・`index.html` の可視テキストのウェイトとサイズの全走査・状態色の見本（`.st span`）の地の混色込みのコントラスト #84・一部選択（indeterminate）の描画を測り、狭い幅での文字付き `.seg` のはみ出しと forced-colors の描画も見る。`tokens-preview.html` では、除外なしの横スクロール #6・`.z-stack` の文字のコントラスト #85・ホバー中の行のコントラスト #90・ページ先頭から Tab で回した button のフォーカスリング幅 #89・#92（`.mbtn`・`.rowsel` を含む。停止数 300 以上。`#states .zs .pop button` と `#states .selbtn` は入力系か button かの判断待ちで、暫定で許容リストに入れている）も測る）、`check-theme.sh`（Issue #53。`theme.js` を実際に動かして初期値 system・保存（`ousiass-theme`）・OS 追従・`aria-pressed`・矢印キー・描画前の `data-theme`・切替後の computed `color-scheme` #83 を確かめる。`check-states.sh` には `theme.js` の文字列を見る grep を置かない）
  - `check-render.sh` の ARIA・キーボード到達（Issue #79〜#82）: aria-hidden の中にフォーカス可能要素がない・溢れてスクロールする要素にキーボードで届く（320 / 375 / 1280px）・`<pre>` と overflow-x:auto に tabindex・role のない div / span に aria-label がない・progressbar と listbox に名前がある・aria-selected と aria-pressed が合う role だけに付く・`#p2 .tree` のシェブロンを実マウスで押すと開く
